Ejercicio de imagenes responsive con boostrap>

10 ejercicios practicos para dominar el manejo de imagenes responsive

📸 Ejercicio 1: Imagen Responsive Básica (.img-fluid)

Objetivo: Aprender a hacer que una imagen se adapte automaticamente con el ancho de su contenedor

Código usado:
<img src=".... alt=... class="img-fluid">

🖼️ Ejercicio 2: Imagen con Borde Thumbnail (.img-thumbnail)

Objetivo Crear una imagen con border redondeado y padding, estilo miniatura

Codigo usado:
<img src=".... alt=... class="img-thumbnail">

🖼️ Ejercicio 3: Imagen con bordes redondeados

Objetivo Aplicar diferentes noveles de redondeo a las esquinas de las imagenes

Codigo usado:
<img src=".... alt=... class="rounded"> <img src=".... alt=... class="rounded-circle"> <img src=".... alt=... class="rounded-pill">

🖼️ Ejercicio 4: Alineacion de Imágenes (float y margin)

ObjetivoControlar la alineacion horizontal de las imagenes

Esta imagen usa la clase .float start para flotar a la izquierda. La clase .me-3 añade margen a la derecha (margin-end) para separar export default class texto de la imagen. El contenido de texto fluye naturalmente alrededor de la imagen

Esta imagen está centrada con .d-block .mx-auto

Codigo usado:

<img src=".... alt=... class="float-start me-3">


<img src=".... alt=... class="d-block mx-auto">
